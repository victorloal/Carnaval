## What went wrong

1. **The brief and the repository disagreed in five places before any code existed.**
   `LICENSE` was The Unlicense while the brief said MIT; the requirements folder was named
   `01_requisitos` while the brief specified `01-requisitos`; a stray empty `ad` file; a
   `.gitignore` that ignored neither `data/raw/` nor `*.pdf` despite the brief requiring it;
   and the brief itself sat at the repository root rather than in `docs/`.

   *Lesson:* verify the filesystem against the prose before planning anything. A document
   that describes a repository is a hypothesis, not a source of truth.

2. **The brief then contradicted the chosen stack.** It specified JWT with rotating
   refresh tokens, which assumes a React admin panel. Choosing Django admin (ADR 0005)
   invalidated that decision and forced a documented deviation.

   *Lesson:* architectural decisions interact. A stack choice is not local — check which
   prior decisions it invalidates, and record the conflict explicitly instead of leaving
   two documents contradicting each other.

3. **A subtask reported writing two large documents that were never written.** The files
   did not exist anywhere on disk.

   *Lesson:* verify that delegated work actually landed before relying on it. A completion
   report is not evidence.

4. **`.gitignore` was GitHub's Python template, unmodified.** It ignored `lib/`, which
   would silently drop a real source directory, and it ignored dozens of irrelevant
   frameworks.

   *Lesson:* a generated or copied config is a liability, not a convenience. Review it
   against the actual stack.
